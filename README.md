Harnice is an electrical system CAD tool. 

It designs harnesses for you... and does so much more... *nicely!*

Please visit...
 - [harnice.io](https://harnice.io/) for documentation
 - https://github.com/harnice/harnice/issues to report a bug or feature request
 - harnice.io@gmail.com to send me an email

## Run from a clone

This repository is the Harnice command-line package. From the checkout:

    PYTHONPATH=src python -m harnice -b

That Python needs the libraries named under `dependencies` in `pyproject.toml`.

Documentation and the AI prompts are in `src/harnice/docs/`.
`PYTHONPATH=src python -m harnice --docs` prints that path.
The same pages are at https://harnice.io/.
